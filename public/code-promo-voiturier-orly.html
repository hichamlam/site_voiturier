Questions fréquentes

Sur le code promo
BIENVENUE

Quel est le code promo Direct Voiturier ?
Le code BIENVENUE donne -10% sur votre première réservation de voiturier à l'aéroport Paris-Orly.
Comment utiliser le code BIENVENUE ?
Saisissez vos dates sur la page d'accueil, puis entrez BIENVENUE dans le champ « Code promo » du formulaire de réservation. La réduction apparaît dans le récapitulatif, avant le paiement.
Qui peut en profiter ?
Le code est réservé à une première réservation. Il est vérifié avec votre adresse email : si une réservation a déjà eu lieu avec cette adresse, le code n'est pas accepté.
Le code fonctionne-t-il avec le paiement sur place ?
Oui. La réduction est calculée dans le prix de la réservation, que vous payiez en ligne par carte bancaire ou sur place.
Sur quoi s'applique la réduction ?
Les 10% s'appliquent au montant de votre réservation, options choisies comprises (lavage par exemple). Le détail est affiché dans le récapitulatif.
Peut-on cumuler plusieurs codes promo ?
Non, un seul code promo peut être saisi par réservation.
